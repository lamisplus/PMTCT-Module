## Common Base Columns (PMTCTTransactionalEntity)

All tables inherit these columns from the base entity class:

| Column | Type | Notes |
|--------|------|-------|
| `id` | BIGINT | Auto-generated identity (NOT the PK; insertable=false, updatable=false) |
| `uuid` | VARCHAR(255) | **PRIMARY KEY**. NOT NULL, UNIQUE. |
| `created_date` | TIMESTAMP | Audit - auto-set on creation |
| `created_by` | VARCHAR(255) | Audit - auto-set on creation |
| `last_modified_date` | TIMESTAMP | Audit - auto-set on update |
| `last_modified_by` | VARCHAR(255) | Audit - auto-set on update |
| `facility_id` | BIGINT | Multi-facility support |
| `source` | VARCHAR(50) | "WEB" or "PMTCT" (mobile) |

## Key Schema Changes Across All Tables

### 1. Primary Key Migration (ALL tables)
All PMTCT tables migrated from `id (BIGINT)` as PK to `uuid (VARCHAR)` as PK.
The `id` column still exists as an auto-generated identity but is NOT the primary key.

### 2. Column Renames (ALL tables)
- `person_uuid` → `patient_uuid` (mother tables)
- `mother_person_uuid` → `mother_patient_uuid` (infant tables)

### 3. Standardized Columns Added to ALL tables
- `pmtct_cycle_id` (BIGINT) — links to pregnancy cycle
- `pmtct_cycle_uuid` (VARCHAR) — UUID link to pregnancy cycle
- `source` (VARCHAR) — "WEB" or "PMTCT" (mobile)
- `archived` (BIGINT DEFAULT 0) — soft delete
- `facility_id` (BIGINT) — multi-facility support
- `created_by`, `created_date`, `last_modified_by`, `last_modified_date` — audit trail

### 4. JSONB Consolidation
Individual columns for syphilis/hepatitis testing were consolidated into JSONB columns:
- `pmtct_anc`: syphilis_info, hepatitis_b_info, hepatitis_c_info, urinalysis, vital_signs, counselling
- `pmtct_enrollment`: syphilis_details, hbv_details
- `pmtct_delivery`: labour_details, maternal_interventions, baby_info, newborn_care, postpartum_info
- `pmtct_infant_information`: infant_arv_data, infant_pcr_data, syphilis_prophylaxis, hbv_vaccinations
- `pmtct_infant_visit`: infant_arv_data, infant_pcr_data, mother_art_data, rapid_test_data, hbv_vaccination_data
- `pmtct_hts`: initial_hiv_test, confirmatory_hiv_test, tie_breaker, retesting, confirmatory_test2, tie_breaker2, syphilis_info, hbv_info, partner_info

### 5. Foreign Keys Added
All tables with `patient_uuid` or `mother_patient_uuid` have FK constraints to `patient_person(uuid)`.
